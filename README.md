# Arizona Deal Scout

An interactive MVP for finding and ranking Arizona residential investment
opportunities by value.

## What it includes

- Strategy-aware ranking for overall value, cash flow, appreciation, or lowest
  entry price
- Search and filters for market, budget, property type, and minimum score
- Transparent score breakdown across price advantage, cap rate, cash flow,
  affordability, and market strength
- Responsive list and grid views, property analysis drawer, and a persistent
  shortlist
- Curated illustrative data for eight Arizona markets

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm test
npm run build
```

The included listing data and underwriting figures are illustrative. Connect a
licensed listing feed and verified market data before using this product for
real investment decisions.
